**ccStory** keeps and searches your Claude Code history on your own machine. It is a **beta and not code-signed yet**, so the first launch needs one extra confirmation (see below).

## New in this build: the app is now called ccStory

0.6.0-beta.1 shipped as *Claude Vault* earlier today. Anthropic's guidelines do not allow "Claude" or "Claude Code" in a third-party product name ([Claude Code legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)), so the app is renamed. Nothing else changed.

- If you installed beta.1, install this one and delete *Claude Vault*. On first launch ccStory moves your index, favorites, tags and backups from the old data folder automatically.
- The installer names start with `ccStory-` now.

**Opening an unsigned build**

- **macOS:**
  1. Drag the app to Applications and open it. macOS says it cannot verify the developer; click **Done**.
  2. Go to **System Settings → Privacy & Security** and click **Open Anyway** next to "ccStory was blocked". On macOS 14 and earlier, right-click the app and choose **Open** instead.
  3. Alternatively, in a terminal: `xattr -dr com.apple.quarantine "/Applications/ccStory.app"`.
- **Windows:** if SmartScreen says "Windows protected your PC", choose **More info → Run anyway**.
- **Linux:** `chmod +x` the AppImage and run it, or `sudo apt install ./ccStory-*.deb`.

## What it does

- **Search every session.**
  - Full-text search over all Claude Code conversations, with matches highlighted.
  - Filters by project, role, date and tag, with tool output and meta lines excluded by default.
  - Infix and CJK queries fall back to substring search.
- **Keep what Claude Code deletes.** Transcripts and plans removed by Claude Code's cleanup stay searchable, marked *Archived*. Deleting them is always an explicit action.
- **My prompts.** Only what you typed (no tool output or harness text), de-duplicated, recent or most used, one click to copy.
- **Favorites, tags and templates.** Favorites and tags survive re-indexing and upgrades. Templates take `{{variables}}`.
- **Stats.**
  - Tokens are counted once per API response (not once per log line, which over-counts about 2×).
  - Cost is estimated for Claude models and for the OpenAI models Codex CLI uses.
  - Prompts per day, and the days you opened Vault.
- **Backups.**
  - A daily snapshot of the vault database, plus one before upgrades, purges and restores.
  - Restore from Settings.
  - A database that will not open is recovered from the newest backup automatically.
- **Live and fast.**
  - Indexing runs on a background thread; a 5 GB history takes about a minute.
  - After that, only new lines are read.
  - Typical search latency is under 100 ms on 750k messages.
- **Also:** Codex CLI sessions (best effort), a command palette (⌘/Ctrl+K), Markdown/CSV export, and a Korean and English UI in light and dark themes.

## Privacy

- ccStory only **reads** `~/.claude` (and `~/.codex`). It never writes there.
- Its index and backups live in your user data folder.
- It makes **one** network request: an update check against GitHub Releases. The check sends no conversation data, can be turned off in Settings, and does nothing on unsigned macOS builds.
- It records the dates you opened it, for the Stats tab. Only dates, and only on your machine.

## Known limitations

- Not code-signed: Gatekeeper and SmartScreen ask once, and macOS builds cannot update themselves. Watch this page for new versions.
- Prompt detection is heuristic. A new kind of text that Claude Code injects may show up as a prompt until it is recognised.
- Codex CLI support is best effort (its log format is undocumented).
- Costs are estimates from logged tokens and an editable price table, not billing data. A subscription is not billed per token.

More in [known limitations](https://github.com/RosieOh/ccStory/blob/main/docs/known-limitations.md). Changes are listed in the [CHANGELOG](https://github.com/RosieOh/ccStory/blob/main/CHANGELOG.md).
